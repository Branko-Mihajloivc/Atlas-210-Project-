4. ATT / PRE relays (rockers) — RX only

  • π-pad 100 / 68 / 100 Ω ≈ 10 dB (exact: 96 / 71 / 96 Ω). Relay bypasses or inserts it. PRE relay wired the same way (switch, coil, sense to D6).
  • Only in the receive line after the antenna relay — never in the TX path. Short leads / thin coax.
  • Better: one ON-OFF-ON rocker for ATT – OFF – PRE (both can never be on). Diode cathode (band) to + side.

5. AGC fast/slow — rocker switch, sense D13

  • 2N7000 at PC-300D: gate via 100 Ω from the rocker (+12 V), 100 k gate–GND, source GND, drain via Rfast (~150–330 k, to try) to the AGC hold node on PC-300D.
  • Parts on PC-300D to be identified by value first (hold cap / 1 M discharge R).

6. MODE (button) · CW (sense D4)

Software only: BFO moved to the other side of the crystal filter (5.520.000 ↔ ~5.523.3 MHz, to be set) — LO calculation follows automatically.
